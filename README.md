# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数与异常处理看板：离线补录 → 字段级合并 → 冲突复核 → 批次封存 → 设备事件追溯的一体化巡检流程。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 核心流程

- **离线补录合并**：巡检记录按「房间 + 时间点 + 字段」合并；互补字段直接并入，同值重传幂等跳过；同字段不同值保留两版，记录进入「待复核」。
- **两班同时提交**：同一时间点只接受先到版本，后到的整套版本保留为草稿，可由班组长并入为冲突版本。
- **设备事件追溯**：登记停机 / 校准事件后，影响范围内未封存记录失效并转为「需重判」；已复核封存的快照不改。
- **复核批次**：班组长裁定冲突、确认重判后封存批次，封存时冻结每条记录的有效判定快照。
- **断点恢复**：写盘采用两段式批次日志（先写完整批次，再逐条落盘）；异常关闭后重启只补未完成记录，审计按 opId 幂等不重复。界面可一键模拟异常关闭验证恢复。
- **唯一有效判定**：看板、记录列表、CSV 导出共用 `effectiveVerdict`（`src/domain/engine.ts`）。

## 角色

- 巡检员：离线/在线补录、失效记录重新判定
- 厂务工程师：登记设备停机 / 校准事件
- 班组长：冲突裁定、草稿并入、批次封存
