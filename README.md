# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数、异常处理看板，以及离线巡检到复核封存的可追溯流程。

## 技术栈

React 19 + Vite + TypeScript + 纯前端状态机（localStorage 持久化，可整包替换为后端 API）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109；`npx tsc --noEmit` 类型检查，`npm run build` 生产构建。

## 领域流程

巡检记录、设备事件、复核批次通过统一状态机串成一条链：

1. **离线合并（房间 + 时间点 + 字段）**
   - 不同人改不同字段：合并为同一条逻辑记录，各自版本留痕。
   - 同字段不同值：两版并存、进入待复核；判定临时采用先到版本，看板单独计数。
   - 同值重复提交：去重，只记审计。
2. **两班撞点**：同一房间同一时间点只接受先到版本，后到班次整条保留草稿，复核可人工采纳（仍走合并规则）。
3. **设备事件驱动失效与重判**
   - 停机：停机时间之后由该设备采集的相关字段版本失效。
   - 校准：校准时间之前的相关读数失效；关键测量项（粒子/压差）无新有效值时整条记录判「失效」，活动异常自动关闭，不再按旧版本统计。
   - 恢复不复活旧数据，需复测补录后重新判定。
4. **复核批次封存**：冲突全部裁决后方可封存；封存写入只读快照，后续设备事件、复测、重判均不改写（看板按当前有效判定，封存表保留历史数字）。
5. **写盘失败恢复**：失败时已落盘条目不回滚，完整批次保留在会话中；恢复只补未完成记录，审计按业务幂等键去重不重复。
6. **一致性**：看板、记录列表、导出共用 `selectEffectiveRows` 同一投影与判定指纹（哈希）；判定规则（ISO 5/6/7 粒子限值、压差/温湿度边界）集中在 `src/domain/rules.ts`。

## 页面

- **看板**：活动异常/失效/待复核/草稿/失败会话指标、异常关闭数（审计）、封存批次历史汇总、判定指纹。
- **巡检记录**：逻辑记录合并视图、全部字段版本、冲突裁决、草稿采纳、失效原因。
- **设备事件**：停机/校准/恢复登记与时间线。
- **复核批次**：按待复核冲突 + 活动异常自动建批，裁决完成后封存只读快照。
- **离线同步与审计**：四个一键演练场景、失败注入点、会话恢复、不可变审计日志。
- **导出**：CSV / JSON（含封存快照），与看板同一判定指纹。

```
  components/            六个视图
  store.ts               useSyncExternalStore + localStorage
verify.ts                Node 下 25 条流程断言（esbuild 打包运行）
```
